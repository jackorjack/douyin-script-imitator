## 仿写脚本格式（每条）

```
┌──────────────────────────────────────┐
│ 🎬 仿写脚本 X ｜ 角度：[角度名称]    │
└──────────────────────────────────────┘

🎤 口播文案：
[完整口播文案，每句标明对应原视频第几句]

🎬 画面脚本：

| 时间段 | 画面 | 景别 | 备注 |
|--------|------|------|------|
| 0-3s | [画面描述] | [特写/中景/全景] | [字幕/特效] |
| 3-8s | ... | ... | ... |
| ... | ... | ... | ... |

📝 视频文案（字幕版）：
[适合做视频字幕的精简版文字]

🏷️ 建议标签：[#标签1 #标签2 ...]
```

## 格式要求

- 使用 emoji 图标增加可读性
- 表格对齐，信息清晰
- 口播文案要口语化，避免书面语
- 画面脚本要具体可执行（写得出就能拍得出）
- 每条脚本开头标注仿写角度
